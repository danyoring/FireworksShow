# 노들섬 불꽃놀이 (Fireworks Show)

Unity 파티클 시스템으로 만든 불꽃놀이 신입니다. 배경 음악이 시작될 때부터 끝날 때까지, 곡의 흐름에 맞춰 불꽃을 연출했습니다.

- Unity 버전: 6000.3.23f1 (URP)
- 실행할 씬: `Assets/Scenes/Fireworks.unity`
- BGM: 藤井 風 (Fujii Kaze) - Prema

## 실행 방법

1. Unity Hub에서 이 폴더를 프로젝트로 엽니다.
2. `Assets/Scenes/Fireworks.unity`를 열고 Play 버튼을 누릅니다.

## 배경

노들섬 근처 강변 둑길에서 한강 너머로 불꽃을 올려다보는 장면입니다.

- 앞쪽: 강가 난간, 전봇대와 전선, 신호등, 명지대학교 현수막
- 가운데: 한강과 한강대교 아치, 노들섬, 불꽃 발사 바지선
- 뒤쪽: 강 건너 스카이라인
- 강물에는 건물 불빛과 다리 아치가 비치고(실시간 반사), 불꽃도 수면 위에 일렁이며 비칩니다(가짜 반사).

## 구성

- `Assets/Scripts/Controllers/FireworksController.cs`: 음악 재생 시간을 기준으로 단계(Phase)마다 불꽃 프리팹을 터뜨립니다. 실행 중 스페이스바를 누르면 현재 음악 시간이 Console에 찍힙니다.
- `Assets/Scripts/Gameplay/Fireworks/FireworksReflection.cs`: 불꽃만 따로 찍어 수면 위에 뒤집어 그리는 가짜 반사입니다.
- `Assets/_Street/Editor/StreetSceneBuilder.cs`: 메뉴 **Fireworks → 거리 배경 만들기**로 배경을 다시 만듭니다.
- `Assets/Prefabs/FX/`: 불꽃 파티클 프리팹들(발사 → 폭발 → 잔광을 서브 이미터로 연결)

수업 예제(Hands on Practice 레포의 Fireworks 씬)를 바탕으로 만들었습니다.
